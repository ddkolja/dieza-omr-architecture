01 / SYSTEM MAP

Карта компонентов

◎Пользователь

Загружает произведение, отмечает страницы на превью, запускает обработку, подтверждает данные первой страницы и проверяет партитуру.

Браузер и мобильный клиент

▣Веб-интерфейс

Статические HTML, CSS и JavaScript. Исходный PDF рядом с нотной вёрсткой, редактор, управление проектами и скачивание.

app/static · ui.js · score.js · review.js

◇Доступ и платежи

Dieza SSO, Apple и Telegram для входа; Stripe и App Store для подписок и прав доступа.

Интеграции вне конвейера OMR
HTTPS → Cloudflare → Nginx → 127.0.0.1:8142

⇄FastAPI

Единое приложение принимает файлы, обслуживает API проектов, предпросмотр, подтверждение, правки, скачивание и учётные записи.

app/main.py · Uvicorn, один worker

⚙Очередь

Обработка выполняется через ThreadPoolExecutor(max_workers=1). Статус и прогресс пишутся в проект.

Один выполняемый job одновременно

♫Dieza ML

Текущий маршрут recognize() → recognize_dieza() → app/dieza_ml/service.py. Разбор страниц и сборка полной партитуры.

Собственный действующий движок
PDF страниц → изображение → символы и текст → музыкальная структура → MusicXML/MXL

▤Вход

PDF и изображения объединяются в один source.pdf.

app/ingest.py

◩Модели

Ансамбль трёх U-Net; ONNX Runtime на CPU. E2E-модель даёт второе мнение по длительностям и голосам.

app/dieza_ml/infer.py · e2e

✎Текст

Tesseract и словари читают заголовки, авторов, слова, язык и надписи; слоги привязываются к нотам.

lyrics.py · marks.py
02 / PIPELINE

Путь одного произведения

01 / ПРИЁМ

Файлы

До 100 файлов и 500 страниц. PDF, PNG, JPEG, TIFF, WebP, BMP и GIF собираются в source.pdf.

02 / ВЫБОР

Страницы

По умолчанию все. Пользователь может отметить нужные страницы и выбрать язык; доступен автоопределитель.

03 / ЗРЕНИЕ

Сегментация

Poppler рендерит страницу; нормализация, поиск станов и ансамбль U-Net выделяют музыкальные символы.

04 / СМЫСЛ

Чтение

Определяются ноты, ключи, размеры, такты, голоса, ритм, лиги, динамика, текст, заголовки и авторы.

05 / ПАУЗА

Паспорт

После первой страницы пользователь подтверждает название, автора, состав, размер, темп и язык.

06 / ЭКСПОРТ

Партитура

Страницы объединяются; ритм проверяется, генерируются MusicXML/MXL и архив с отчётом.

Язык и текст. OCR использует Tesseract; язык определяется по письменности и словарям. Строки текста ищутся относительно станов, а слоги выравниваются по нотным колонкам.
Второе мнение. Включённая E2E-модель уточняет голоса, длительности и пропущенные головки. Её сбой не отменяет основное распознавание страницы.
03 / DATA & API

Данные и пользовательский контур

ПроектыВ /data/<job-id>/ лежат job.json, исходный PDF, результаты, версии правок и кэш просмотра. Каталог /data примонтирован с хоста.
Аккаунтыapp/accounts.py использует SQLite в каталоге данных для входа, токенов, доступов и промокодов.
Результатыscore.musicxml, score.mxl и results.zip с report.json. SVG-предпросмотр создаётся отдельно по запросу через Verovio.
ПлатежиStripe через app/billing.py, App Store через app/appstore.py.
ЗагрузкаPOST /api/jobs и POST /api/jobs/{id}/start. Отдельное API предпросмотра выбранных страниц.
СостояниеGET /api/jobs, GET /api/jobs/{id}, подтверждение паспорта, отмена и возобновление.
ПроверкаAPI MusicXML, SVG и правок: исправление высоты ноты или всей партитуры, сохранение версии.
Граница доступаMiddleware проверяет доступ, Origin и принадлежность проекта пользователю.
04 / DEPLOYMENT

Развёртывание

Интернет

omr.dieza.net → Cloudflare → Nginx.

Контейнер

Docker Compose: dieza-omr, порт 127.0.0.1:8142 → 8000; лимиты 5 GiB RAM, 5 CPU, 256 процессов.

Хранение

Bind mount ./data:/data. Приватная конфигурация на сервере передаётся через .env.

Среда: Ubuntu 24.04, Python/FastAPI, Poppler, Tesseract, PyTorch CPU и ONNX Runtime. Контейнер работает от непривилегированного пользователя; дополнительные capabilities и повышение привилегий отключены.
05 / INTERPRETATION

Как оценивать результат

Экспорт ≠ проверенная точность

Сформированный MusicXML может содержать ошибки. quality.py отмечает известные потери, а в остальных случаях показывает «Точность ещё не проверена». Просмотр и редактор нужны для сверки с оригиналом.

Действующий путь

В дереве проекта есть более ранние и вспомогательные модули. Текущий вызов распознавания использует dieza_ml. Скрипты обучения не запускаются при обработке пользовательского запроса.

Проверены: app/main.py, app/ingest.py, app/dieza_ml, app/review.py, app/quality.py, app/accounts.py, app/billing.py, Dockerfile, compose.yaml и конфигурация Nginx.

Эта схема не содержит содержимого .env, ключей, весов моделей, исходных нот или пользовательских файлов.
